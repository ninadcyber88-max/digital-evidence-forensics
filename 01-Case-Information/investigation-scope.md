# Investigation Scope

## In Scope

### File System
- File metadata
- File hashes
- Created/Modified/Accessed timestamps
- Deleted files
- Directory structure

### Browser
- History
- Downloads
- Search activity
- Bookmarks
- Cookies

### Windows
- Event Logs
- Registry
- Prefetch
- Recent activity

### USB
- Device registration
- Device identifiers
- Connection artifacts

### Memory
- Processes
- Network connections
- Command-line artifacts

### Timeline
Correlation of artifacts from multiple sources.

## Out of Scope

- Unauthorized access
- Real confidential information
- Third-party private data
- Destructive testing
- Modification of original evidence
